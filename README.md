# Restful Booker API Testing

## Project Overview
API Testing project using Postman
to test the Restful Booker API.

## Tools Used
- Postman
- REST API
- JavaScript
- GitHub

## API Operations Tested
- Health Check
- Authentication
- Create Booking
- Get Booking IDs
- Get Booking
- Update Booking (PUT)
- Partial Update (PATCH)
- Delete Booking

## Testing Activities
- Status Code Validation
- Response Body Validation
- JSON Schema Checks
- Response Time Checks
- Positive and Negative Testing
- Automated Test Scripts

## How to Run
1. Download the Postman Collection.
2. Import it into Postman.
3. Run the Auth request.
4. Run the remaining requests in order.
5. View test results in Postman.
